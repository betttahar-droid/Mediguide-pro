# Vaccine Fridge v7 — Reference-Fit Specification

This implementation brief is derived from all five supplied references and the cited technical research in `report-source.md`.

## Geometry rules

- Preserve the locked 39 × 37 × 96 model-pixel appliance envelope.
- Build the silhouette from crown, cabinet, and base masses.
- Show at least four readable front depth planes: hull, cavity, rail/frame, fittings.
- Use 1–2 px stepped edge bands and 2–4 px corner/hardware blocks.
- Make rails, hinges, shelves, vents, slots, and handles real geometry.
- Generate repeated structures from one measured template and a loop.
- Keep faces flat; use no smooth bevels.
- Add only a few asymmetric fittings, anchored to functional locations.

## Texture rules

- Use 3–5 quantized colors per material family.
- Keep 75–90% of broad panel area visually quiet.
- Use deliberate clusters 2–8 model pixels long and 1–3 pixels thick.
- Reserve isolated single pixels for fasteners and indicator lights.
- Put bright catches on top/left and dark bands on bottom/right.
- Use material-specific marks: steel seams, enamel notches, glass stairs, grille slots.
- Keep decals fixed-size and socket-anchored; never scale them with the cabinet.
- Tile ordinary material fields at stable world/model-pixel density.
- Preserve corners with tiled nine-slice logic.
- Enforce nearest-neighbor sampling, no decal mipmaps, sRGB colors, 3 px internal transparency, and 4 px atlas gutters.
- Reject random dirt, cloudy gradients, soft antialiasing, and duplicated painted geometry.

## Audit thresholds

- Envelope/proportions unchanged: required.
- New structural details implemented as geometry: required.
- Repeating service slots generated by loop: required.
- Nano decal count: 8–12 purposeful motifs.
- Internal transparent margin: ≥3 px.
- Atlas gutter: ≥4 px.
- Largest connected decal extent: ≤8 × 10 logical pixels.
- Broad-panel quiet area: ≥75%.
- glTF sampler magnification/minification: 9728/9728.
- Regression suite and production build: pass.
